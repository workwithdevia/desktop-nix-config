# Niri (compositor) — inactivo

Este directorio es un espacio reservado para una futura sesión **Niri** como
compositor alternativo a Sway (Wayland).

Actualmente **no se importa** en ningún `default.nix` y **no forma parte** del
sistema en ejecución.

- Ver `ROADMAP.md` §6.3 para la decisión de activarlo como sesión opcional del
  greeter (`displayManager`) o eliminarlo definitivamente.
